The story in one sentence

Answer now.
Verify after.

A voice-first RAG system with one honest promise: show useful evidence fast, then let a slower verifier improve—or overturn—it.

The design move

Two clocks.
One answer.

The fast clock gets evidence onto the screen. The slow clock decides whether that evidence deserves trust.

The mental model

Three layers, not one magic model

01

Hear

Sarvam turns Indic speech into a query. STT is measured separately from the RAG SLA.

02

Find

BM25 and Qdrant retrieve lexical evidence, then an extractive selector chooses a defensible span.

03

Earn trust

Async validation can keep, repair, synthesize, or refuse the first answer.

What to say

Narrator script

“Speculative RAG starts with a useful guess. Speech becomes text, BM25 finds evidence, and an extractive selector returns a passage before a hosted model could respond. Then, in the background, Claude checks whether that answer is grounded. If not, the system reranks, regenerates, synthesizes—or admits it cannot answer.”
Important clarification

The name is inspired by speculation—not the paper’s exact algorithm.

This project does not use specialist/generalist parallel drafting. Its “speculative” behavior is closer to speculative decoding: commit cheaply, validate asynchronously.
