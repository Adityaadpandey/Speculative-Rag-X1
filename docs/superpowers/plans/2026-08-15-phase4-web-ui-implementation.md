# Phase 4: Interactive Web UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the RAG pipeline (Phase 2 hot path + Phase 3 STT/reflect legs) an interactive local web UI: type a question or provide audio, see the extractive answer with guardrail outcome and per-stage latency, and — for `ANSWERED` results — a non-blocking async groundedness review.

**Architecture:** A FastAPI app (`webapp/main.py`) loads one `Embedder` and one `Retriever` per available Qdrant collection ONCE at startup (module-level state), then exposes four JSON endpoints (`/api/collections`, `/api/query`, `/api/transcribe`, `/api/reflect`) plus `GET /` serving a static single-page frontend (`webapp/static/*`). The frontend is plain HTML/CSS/JS (no build step) using `fetch()` and `MediaRecorder`. A thin launcher (`scripts/serve_ui.py`) runs `uvicorn webapp.main:app`.

**Tech Stack:** FastAPI, uvicorn, python-multipart (new deps, added via `uv add`); reuses existing `speculative_rag.pipeline.run_pipeline`, `speculative_rag.stt.transcribe_audio`, `speculative_rag.reflect.check_groundedness_llm`, `Embedder`, `Retriever` unchanged.

## Global Constraints

- No changes to `src/speculative_rag/*` — the web app is a pure HTTP layer over the existing, unchanged package.
- No websockets/SSE. The groundedness review's non-blocking feel comes from the frontend calling `/api/reflect` as a second, separate `fetch()` after `/api/query` already resolved — plain sequential async HTTP.
- No audio longer than Sarvam's 30s synchronous-endpoint limit. The mic recorder auto-stops at 30s; no chunking, no batch-API fallback.
- No frontend build step, no npm/node toolchain. Plain HTML/CSS/JS served as static files.
- No changes to the existing CLI scripts (`scripts/answer.py`, `scripts/voice_answer.py`, `scripts/run_latency_eval.py`, `scripts/run_full_latency_eval.py`) — all remain as-is, independently usable.
- No authentication/multi-user support. No persistence across page refreshes — no database, no query history, no session storage.
- New dependencies, added via `uv add`: `fastapi`, `uvicorn[standard]`, `python-multipart`.
- All endpoints return JSON except `GET /` and `GET /static/*`.
- Unhandled exceptions on any endpoint return HTTP 500 with `{"error": str(exc)}` via a FastAPI exception handler — the frontend always gets JSON back, never an HTML error page.
- Tests use fakes-over-real-model (same pattern as `tests/test_pipeline.py`): no real network calls, no real model loads, no real Qdrant collection required. Real end-to-end exercise of `/api/transcribe` and `/api/reflect` is manual, same as `voice_answer.py` today.

"""Phase 4 web UI: thin FastAPI HTTP layer over the unchanged Phase 2/3
pipeline (pipeline.run_pipeline, stt.transcribe_audio,
reflect.check_groundedness_llm). Loads Embedder + one Retriever per
available Qdrant collection ONCE at startup (module-level state), reused
across requests -- the same "load once, serve many queries" pattern
scripts/answer.py uses in its input loop."""

import os
from contextlib import asynccontextmanager
from pathlib import Path

from fastapi import FastAPI, Request
from fastapi.responses import FileResponse, JSONResponse
from fastapi.staticfiles import StaticFiles
from qdrant_client import QdrantClient

from speculative_rag.config import LANGUAGE_SOURCES, SETTINGS
from speculative_rag.embedding import Embedder
from speculative_rag.retrieval import Retriever

STATIC_DIR = Path(__file__).resolve().parent / "static"
KNOWN_STRATEGIES = ["native", "sliding_window", "sentence", "metadata"]
KNOWN_LANGUAGES = [source.language for source in LANGUAGE_SOURCES]

_EMBEDDER: Embedder | None = None
_RETRIEVERS: dict[str, Retriever] = {}
_COLLECTIONS: list[dict[str, str]] = []


def _parse_collection_name(name: str) -> dict[str, str] | None:
    for language in KNOWN_LANGUAGES:
        prefix = f"{language}_"
        if name.startswith(prefix):
            strategy = name[len(prefix):]
            if strategy in KNOWN_STRATEGIES:
                return {"language": language, "strategy": strategy}
    return None


def _load_state() -> None:
    global _EMBEDDER, _RETRIEVERS, _COLLECTIONS
    _EMBEDDER = Embedder()
    client = QdrantClient(path=str(SETTINGS.qdrant_path))
    retrievers: dict[str, Retriever] = {}
    collections: list[dict[str, str]] = []
    for collection in client.get_collections().collections:
        parsed = _parse_collection_name(collection.name)
        if parsed is None:
            continue
        retrievers[collection.name] = Retriever(client, collection.name)
        collections.append(parsed)
    _RETRIEVERS = retrievers
    _COLLECTIONS = collections


@asynccontextmanager
async def lifespan(app: FastAPI):
    _load_state()
    yield


app = FastAPI(lifespan=lifespan)
app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")


@app.exception_handler(Exception)
async def unhandled_exception_handler(request: Request, exc: Exception) -> JSONResponse:
    return JSONResponse(status_code=500, content={"error": str(exc)})


@app.get("/")
async def index() -> FileResponse:
    return FileResponse(STATIC_DIR / "index.html")


@app.get("/api/collections")
async def get_collections() -> dict:
    return {
        "collections": _COLLECTIONS,
        "sarvam_key_configured": bool(os.environ.get("SARVAM_API_KEY")),
        "anthropic_key_configured": bool(os.environ.get("ANTHROPIC_API_KEY")),
    }
```

    query_text: str
    language: str
    strategy: str


@app.post("/api/query")
async def post_query(body: QueryRequest) -> JSONResponse | dict:
    collection_name = f"{body.language}_{body.strategy}"
    retriever = _RETRIEVERS.get(collection_name)
    if retriever is None:
        return JSONResponse(status_code=404, content={"error": f"No such collection '{collection_name}'"})

    result = run_pipeline(
        body.query_text,
        _EMBEDDER,
        retriever,
        off_topic_threshold=SETTINGS.off_topic_threshold,
        groundedness_threshold=SETTINGS.groundedness_threshold,
        top_k=SETTINGS.answer_top_k,
    )

    answer = None
    if result.answer is not None:
        answer = {
            "text": result.answer.text,
            "source_passage_id": result.answer.source_passage_id,
            "retrieval_score": result.answer.retrieval_score,
            "groundedness_score": result.answer.groundedness_score,
        }

    return {
        "outcome": result.outcome.value,
        "answer": answer,
        "refusal_reason": result.refusal_reason,
        "timings": [{"stage": t.stage, "elapsed_ms": t.elapsed_ms} for t in result.timings],
        "total_ms": result.total_ms,

@app.post("/api/transcribe")
async def post_transcribe(file: UploadFile = File(...), language: str = Form(...)) -> JSONResponse | dict:
    language_code = BCP47_LANGUAGE_CODES.get(language, SETTINGS.sarvam_default_language_code)
    suffix = Path(file.filename or "").suffix or ".wav"
    contents = await file.read()

    with tempfile.NamedTemporaryFile(suffix=suffix, delete=False) as tmp:
        tmp.write(contents)
        tmp_path = Path(tmp.name)

    try:
        stt_start = time.perf_counter()
        transcript = transcribe_audio(tmp_path, language_code)
        stt_ms = (time.perf_counter() - stt_start) * 1000.0
    except SarvamAPIKeyMissingError as exc:
        return JSONResponse(status_code=400, content={"error": str(exc)})
    finally:
        tmp_path.unlink(missing_ok=True)

    return {"transcript": transcript, "stt_latency_ms": stt_ms}
```

class ReflectRequest(BaseModel):
    query_text: str
    language: str
    strategy: str
    answer_text: str


@app.post("/api/reflect")
async def post_reflect(body: ReflectRequest) -> JSONResponse | dict:
    collection_name = f"{body.language}_{body.strategy}"
    retriever = _RETRIEVERS.get(collection_name)
    if retriever is None:
        return JSONResponse(status_code=404, content={"error": f"No such collection '{collection_name}'"})

    query_vector = _EMBEDDER.embed_query(body.query_text)
    retrieval = retriever.search(query_vector, k=1)
    source_text = retrieval.top.chunk.text if retrieval.top is not None else ""

    reflect_start = time.perf_counter()
    verdict = check_groundedness_llm(body.answer_text, source_text)
    reflect_ms = (time.perf_counter() - reflect_start) * 1000.0

    return {
        "grounded": verdict.grounded,
        "reasoning": verdict.reasoning,
        "reflect_latency_ms": reflect_ms,
    }

- [ ] **Step 3: Write `webapp/static/app.js`**

```javascript
const state = {
  sarvamKeyConfigured: false,
  anthropicKeyConfigured: false,
};

let mediaRecorder = null;
let recordedChunks = [];
let recordTimer = null;

const languageSelect = document.getElementById("language-select");
const strategySelect = document.getElementById("strategy-select");
const queryTextInput = document.getElementById("query-text");
const askBtn = document.getElementById("ask-btn");
const audioFileInput = document.getElementById("audio-file");
const recordBtn = document.getElementById("record-btn");
const recordCountdown = document.getElementById("record-countdown");
const audioDisabledNote = document.getElementById("audio-disabled-note");
const resultPanel = document.getElementById("result-panel");
const outcomeBadge = document.getElementById("outcome-badge");
const answerBlock = document.getElementById("answer-block");
const answerText = document.getElementById("answer-text");
const answerSourceId = document.getElementById("answer-source-id");
const answerRetrievalScore = document.getElementById("answer-retrieval-score");
const answerGroundednessScore = document.getElementById("answer-groundedness-score");
const refusalText = document.getElementById("refusal-text");
const latencyTableBody = document.querySelector("#latency-table tbody");
const reviewPanel = document.getElementById("review-panel");
const reviewStatus = document.getElementById("review-status");
const reviewResult = document.getElementById("review-result");
const reviewBadge = document.getElementById("review-badge");
const reviewReasoning = document.getElementById("review-reasoning");
const reviewLatencyMs = document.getElementById("review-latency-ms");
const errorBanner = document.getElementById("error-banner");

const OUTCOME_LABELS = {
  answered: "ANSWERED",
  off_topic_refused: "OFF-TOPIC",
  unsafe_input_refused: "UNSAFE INPUT",
  ungrounded_refused: "UNGROUNDED",
};

function showError(message) {
  errorBanner.textContent = message;
  errorBanner.hidden = false;
}

function clearError() {
  errorBanner.hidden = true;
  errorBanner.textContent = "";
}

async function loadCollections() {
  const response = await fetch("/api/collections");
  const data = await response.json();
  state.sarvamKeyConfigured = data.sarvam_key_configured;
  state.anthropicKeyConfigured = data.anthropic_key_configured;

  const languages = [...new Set(data.collections.map((c) => c.language))];
  const strategiesByLanguage = {};
  for (const c of data.collections) {
    (strategiesByLanguage[c.language] ??= []).push(c.strategy);
  }

  languageSelect.innerHTML = "";
  for (const language of languages) {
    const opt = document.createElement("option");
    opt.value = language;
    opt.textContent = language;
    languageSelect.appendChild(opt);
  }
  languageSelect.value = languages.includes("hi") ? "hi" : (languages[0] ?? "");

  function refreshStrategies() {
    const strategies = strategiesByLanguage[languageSelect.value] ?? [];
    strategySelect.innerHTML = "";
    for (const strategy of strategies) {
      const opt = document.createElement("option");
      opt.value = strategy;
      opt.textContent = strategy;
      strategySelect.appendChild(opt);
    }
    strategySelect.value = strategies.includes("native") ? "native" : (strategies[0] ?? "");
  }
  languageSelect.addEventListener("change", refreshStrategies);
  refreshStrategies();

  if (!state.sarvamKeyConfigured) {
    audioFileInput.disabled = true;
    recordBtn.disabled = true;
    audioDisabledNote.hidden = false;
  }
}

function resetPanels() {
  clearError();
  resultPanel.hidden = true;
  reviewPanel.hidden = true;
  answerBlock.hidden = true;
  refusalText.hidden = true;
  reviewResult.hidden = true;
  reviewStatus.hidden = false;
  latencyTableBody.innerHTML = "";
}

function renderResult(data) {
  resultPanel.hidden = false;
  outcomeBadge.textContent = OUTCOME_LABELS[data.outcome] ?? data.outcome;
  outcomeBadge.className = `badge badge-${data.outcome}`;

  if (data.outcome === "answered") {
    answerBlock.hidden = false;
    refusalText.hidden = true;
    answerText.textContent = data.answer.text;
    answerSourceId.textContent = data.answer.source_passage_id;
    answerRetrievalScore.textContent = data.answer.retrieval_score.toFixed(3);
    answerGroundednessScore.textContent = data.answer.groundedness_score.toFixed(3);
  } else {
    answerBlock.hidden = true;
    refusalText.hidden = false;
    refusalText.textContent = data.refusal_reason;
  }

  latencyTableBody.innerHTML = "";
  for (const timing of data.timings) {
    const row = document.createElement("tr");
    row.innerHTML = `<td>${timing.stage}</td><td>${timing.elapsed_ms.toFixed(2)} ms</td>`;
    latencyTableBody.appendChild(row);
  }
  const totalRow = document.createElement("tr");
  totalRow.innerHTML = `<td><strong>TOTAL</strong></td><td><strong>${data.total_ms.toFixed(2)} ms</strong></td>`;
  latencyTableBody.appendChild(totalRow);
}

async function startReview(queryText, answerTextValue) {
  reviewPanel.hidden = false;
  reviewStatus.hidden = false;
  reviewResult.hidden = true;

  if (!state.anthropicKeyConfigured) {
    reviewStatus.textContent = "ANTHROPIC_API_KEY not set — skipping groundedness review";
    return;
  }

  reviewStatus.textContent = "checking groundedness...";
  try {
    const response = await fetch("/api/reflect", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        query_text: queryText,
        language: languageSelect.value,
        strategy: strategySelect.value,
        answer_text: answerTextValue,
      }),
    });
    const data = await response.json();
    if (!response.ok) {
      reviewStatus.textContent = `review failed: ${data.error ?? "unknown error"}`;
      return;
    }
    reviewStatus.hidden = true;
    reviewResult.hidden = false;
    reviewBadge.textContent = data.grounded ? "GROUNDED" : "NOT GROUNDED";
    reviewBadge.className = `badge ${data.grounded ? "badge-grounded" : "badge-not-grounded"}`;
    reviewReasoning.textContent = data.reasoning;
    reviewLatencyMs.textContent = data.reflect_latency_ms.toFixed(2);
  } catch (err) {
    reviewStatus.textContent = `review failed: ${err.message}`;
  }
}

async function runQuery(queryText) {
  resetPanels();
  if (!queryText.trim()) {
    return;
  }
  let response;
  let data;
  try {
    response = await fetch("/api/query", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        query_text: queryText,
        language: languageSelect.value,
        strategy: strategySelect.value,
      }),
    });
    data = await response.json();
  } catch (err) {
    showError(`query failed: ${err.message}`);
    return;
  }
  if (!response.ok) {
    showError(data.error ?? "query failed");
    return;
  }

  renderResult(data);
  if (data.outcome === "answered") {
    startReview(queryText, data.answer.text);
  }
}

askBtn.addEventListener("click", () => {
  runQuery(queryTextInput.value);
});
queryTextInput.addEventListener("keydown", (e) => {
  if (e.key === "Enter") {
    runQuery(queryTextInput.value);
  }
});

async function transcribeAndQuery(blob, filename) {
  resetPanels();
  const formData = new FormData();
  formData.append("file", blob, filename);
  formData.append("language", languageSelect.value);

  let response;
  let data;
  try {
    response = await fetch("/api/transcribe", { method: "POST", body: formData });
    data = await response.json();
  } catch (err) {
    showError(`transcription failed: ${err.message}`);
    return;
  }
  if (!response.ok) {
    showError(data.error ?? "transcription failed");
    return;
  }
  queryTextInput.value = data.transcript;
  runQuery(data.transcript);
}

audioFileInput.addEventListener("change", () => {
  const file = audioFileInput.files[0];
  if (file) {
    transcribeAndQuery(file, file.name);
  }
});

recordBtn.addEventListener("click", async () => {
  if (mediaRecorder && mediaRecorder.state === "recording") {
    mediaRecorder.stop();
    return;
  }
  try {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    recordedChunks = [];
    mediaRecorder = new MediaRecorder(stream);
    mediaRecorder.addEventListener("dataavailable", (e) => {
      if (e.data.size > 0) {
        recordedChunks.push(e.data);
      }
    });
    mediaRecorder.addEventListener("stop", () => {
      clearInterval(recordTimer);
      recordCountdown.textContent = "";
      recordBtn.textContent = "Record";
      stream.getTracks().forEach((track) => track.stop());
      const blob = new Blob(recordedChunks, { type: "audio/webm" });
      transcribeAndQuery(blob, "recording.webm");
    });
    mediaRecorder.start();
    recordBtn.textContent = "Stop";

    let secondsLeft = 30;
    recordCountdown.textContent = `${secondsLeft}s`;
    recordTimer = setInterval(() => {
      secondsLeft -= 1;
      recordCountdown.textContent = `${secondsLeft}s`;
      if (secondsLeft <= 0) {
        mediaRecorder.stop();
      }
    }, 1000);
  } catch (err) {
    showError(`microphone access failed: ${err.message}`);
  }
});

loadCollections().catch((err) => showError(`failed to load collections: ${err.message}`));
```
